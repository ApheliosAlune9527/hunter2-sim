# 建图保存与导出工具实现记录

目标：提供一次完整、可复制的实验室建图流程，将新采集点云持续写盘并传回 Windows。

设计依据：现有 FAST-LIVO2 的正数 interval 会按次数写编号 PCD，并释放保存缓存；SIGINT 的 savePCD 只处理负数 interval。选择 interval=1，沿用现有算法，每次非空输出即写盘。建立独立运行目录，将私有工作区原 PCD 目录完整归档，再让输出目录指向新运行的 pcd 子目录。

范围：仅操作 /home/car/hz_ws；保留师兄的源工作区与原配置。启动 XT32、原 CH104 Python 驱动、D435i RGB、建图与可选 RViz。脚本不启动底盘、导航或发布运动指令。内存检查在不足 4 GiB 时通知本次传感器与建图退出，不强杀。

验证：先用真实二进制 PCD 样本测试截断检测、合并点数/颜色/顺序、预览抽稀以及目标文件保护；测试进程选择拒绝其他用户、其他 ROS_HOME、其他程序；验证会话参数复制不会修改原配置。Windows 工具通过校验和检查传输，并拒绝危险归档路径。
