# 花簇戒指 · 三维造型初稿 v01

根据用户提供的单张戒指插画重建。主花、侧花、两枚后方花苞及枝条戒臂均为真实三维几何，隐藏的背面结构为本稿补全。

## 本版尺寸

- 名义内径：17 mm（临时尺寸，用户已选择先看造型，之后再定圈号）。
- 外形包围尺寸：约 20.83 × 11.53 × 30.30 mm。
- 该尺寸用于本轮比例预览；不能根据原插画测得实际原物尺寸。

## 文件

- `floral-ring-v01-id17mm.stl`：单个封闭实体，按毫米导出，未添加打印支撑。
- `floral-ring-v01.glb`：可旋转查看的三维造型，保留花瓣与枝条分组。GLB 按标准以米存储。
- `preview-hero.png` / `preview-side.png` / `preview-back.png`：同一个模型的不同视角。
- `viewer.html`：本地三维查看器，配套 `vendor/` 与 GLB 使用；需要通过本地网页服务打开。
- `build_ring.py` / `design-parameters.json`：本稿的构建来源与参数，便于后续继续调整。
- `export-verification.json`：重新读取最终 STL 后得到的检查结果。

## 已完成检查

重新读取导出的 STL：水密、法线方向一致、正体积、仅一个连通实体。内径截面数值约 16.999～17.001 mm。

## 下一步

先确认主花大小、花瓣形状、花苞、戒臂纹理及花朵高度，再调整正式圈号。实际打印或铸银前仍需按最终材料与加工店要求确认薄壁、缝隙、支撑、收缩和打磨余量。本版没有进行铸造工艺验收。

## 构建依赖

如需重新生成模型，需要 Python 及 numpy、scipy、trimesh、manifold3d、rtree；运行 `build_ring.py`。

查看器使用 Three.js 0.170.0（MIT 许可），配套脚本位于 `vendor/`。
