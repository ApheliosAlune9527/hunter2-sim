## 1. 确认小车 IP、上传工具

在小车的检查终端运行：

```bash
hostname -I
```

选用于远程连接的局域网 IP。此前使用的是 192.168.31.204，以当前结果为准。192.168.8.100 是雷达网卡地址。

在 Windows 本地 PowerShell 中完整复制下面这一段，按提示输入小车 IP。SSH 返回的主机名必须是 car-NUC15JNKU7X4，才会上传工具。

```powershell
$hzRobotIp = Read-Host '输入小车局域网 IP'
$hzRobotName = (& ssh "car@$hzRobotIp" hostname | Out-String).Trim()
if ($LASTEXITCODE -ne 0 -or $hzRobotName -ne 'car-NUC15JNKU7X4') { throw '没有连接到预期的小车，停止上传' }
scp 'F:\rob-memory\hz_mapping_tools_20261011\hz_mapping_session.py' 'F:\rob-memory\hz_mapping_tools_20261011\pcd_export.py' "car@${hzRobotIp}:/home/car/hz_ws/scripts/"
if ($LASTEXITCODE -ne 0) { throw '上传未完成，先处理上传错误' }
```

密码只在本地 PowerShell 的密码提示处输入。保留这个 Windows 窗口，下载时继续使用 $hzRobotIp。

## 2. 在小车上停止旧会话、建立新一轮

检查终端依次执行，上一条成功后再执行下一条。有错误时停止后续操作，保留输出。

```bash
python3 -B /home/car/hz_ws/scripts/hz_mapping_session.py status
```

```bash

```


stop 只匹配当前用户、ROS_DOMAIN_ID=88、ROS_HOME=/home/car/hz_ws/.ros 的本次传感器/建图程序，显示 PID 后发送 SIGINT；先停显示与传感器，再停建图。发现多个同类进程会停止操作，不强杀。

prepare 会检查雷达 UDP 2368、IMU 端口和磁盘空间，建立 lab_日期_时间 的独立地图目录，并打印路径。每次重新建图都要新 prepare，不能在同一轮重启建图，避免编号从头覆盖。

## 3. 开四个终端启动采集和建图

每个终端分别执行一条。工具会设置终端标题和 ROS 环境，加载系统 ROS、D435i 与 hz_ws 环境。保持各终端打开。

终端 A：XT32。


终端 B：CH104。

终端 C：D435i，仅 RGB 640×480、15Hz。


## 4. 检查输入和自动保存，再开 RViz

在检查终端复制这段环境设置：

```bash
source /opt/ros/humble/setup.bash
source /home/car/d435i_ws/install/local_setup.bash
source /home/car/hz_ws/install/local_setup.bash
export ROS_DOMAIN_ID=88 RMW_IMPLEMENTATION=rmw_fastrtps_cpp ROS_LOCALHOST_ONLY=0 ROS_LOG_DIR=/home/car/hz_ws/logs/ros ROS_HOME=/home/car/hz_ws/.ros PYTHONDONTWRITEBYTECODE=1
```

依次检查，应该接近 10Hz、100Hz、15Hz：

```bash
timeout -s INT -k 2s 8s ros2 topic hz /lidar_points
```

```bash
timeout -s INT -k 2s 8s ros2 topic hz /imu/data
```

```bash
timeout -s INT -k 2s 8s ros2 topic hz /camera/camera/color/image_raw
```

确认新保存参数，必须为 Integer value is: 1：

```bash
ros2 param get /laserMapping pcd_save.interval
```

静止约 30 秒后，在检查终端开启监测：

```bash
python3 -B /home/car/hz_ws/scripts/hz_mapping_session.py watch
```

它每 5 秒显示可用内存、磁盘空间、PCD 文件数和建图 PID。必须看到建图 PID 存在、PCD 文件数持续增加，才开始移动。若文件数一直是 0 或输入没有频率，先停止并检查日志。

可选终端 E：RViz。

```bash
python3 -B /home/car/hz_ws/scripts/hz_mapping_session.py rviz
```

Fixed Frame 为 camera_init，RGB 历史点云保留 5 秒。RViz 主要显示近期点云；更早的扫描已经写在文件中。RViz 的 Save 保存显示配置，地图的保存由建图节点自动完成。

## 5. 使用手持遥控器完成一圈扫描

移动前必须确认充电线已拔掉、周围有低速移动空间。此流程没有启动底盘或导航控制节点，也不发布运动指令；实际移动由原有手持遥控器完成。

静止初始化和落盘检查通过后，低速、平缓地扫描一圈实验室，避免快速转向。完成一圈就停稳并结束本轮，不长时间原地等待。建议这一轮控制在数分钟内，约 5–8 分钟；实际可用时间取决于内存增长。

若可用内存不足 4 GiB、磁盘不足 2 GiB，或者建图 PID 消失，watch 会通知本轮传感器与建图退出。它不控制底盘刹车；看到停止提示时，用手持遥控器让小车停稳。即使进程意外终止，之前完成写盘的编号 PCD 仍保留；最新正在写的文件需要检查。
