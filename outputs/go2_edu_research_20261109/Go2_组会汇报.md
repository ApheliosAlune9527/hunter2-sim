# Go2 组会汇报（1 页）

日期：2026-11-09

## 一、我们买到了什么

- Unitree Go2 EDU：15 kg、0–3.7 m/s、爬 40°、越障 16 cm、负载约 8 kg、15000 mAh（2–4 h）、4D LiDAR L2（360°×96°，30 m）、前视相机、足端力传感器。
- **关键未知项**：有没有 Docking Station（Orin Nano 8GB / NX 16GB）、D435i 深度相机、MID-360/XT16 外置雷达、D1 机械臂。这些是选配，决定"机载能跑什么"。
- 结论：它是一台能走、能看、能联网、能二次开发的研究平台；不是机械臂，不是高精度平台。

## 二、论文库告诉我们什么

- 实际清点：**四足 666 + 人形 632 = 1298 篇**（消息里的 576/437 是旧统计）。
- **217 篇**四足论文提到 Go2；主类：导航 62、运动 RL 47、VLN/VLA 34、loco-manipulation 26。
- Go2 相关论文 97% 在 200 号以后 → 新论文默认用 Go2。
- 结论：**"用 Go2 做 X"已经不构成创新**；要在 X 的具体缺口上做。

## 三、我们最适合做的三件事

1. **把 Hunter 的 AgentVLN 栈迁到 Go2**（最短路径）
   - 已有：Qwen2.5-VL-3B 本地服务、任务编排、Nav2、评测脚本；
   - 要改：`/cmd_vel` → `SportClient.Move` 桥、相机/LiDAR 外参、四足安全策略；
   - 目标：5 条路线单 Agent 基线 → 12–20 条路线。
2. **长时程导航的"记忆—复核—重规划"触发机制**
   - 对照：单 Agent / 固定多角色 / 规则触发 / 学习触发；
   - 指标：SR、SPL、nDTW、接管、调用成本、延迟；
   - 一台狗可闭环，不需要第二台。
3. **学习型局部导航 vs 传统导航的安全—效率对比**
   - Nav2 vs RL vs RL+CBF，同场景同指标；
   - 需要训练 GPU（本机没有，用服务器）。
