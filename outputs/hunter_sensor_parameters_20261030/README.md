将新光心直接放入旧名义外壳后，Ogre1 相机画面只有背景；对照测试表明遮挡来自该相机外壳网格。为保留完整网格和可用图像，将外壳及其安装框整体平移 `(-13.65, -2.5, -6)` mm，让其沿用此前外壳与光心的相对位置；其余外观组件的网格和位置未改变。新的光心没有改变，平移仅用于仿真模型对齐，不是实车外壳位置的测量。红色目标的实际投影与居中方形像素模型预测相差约 1 像素以内，见 [最终相机投影结果](probes/8ff47460e971/check.json)。
