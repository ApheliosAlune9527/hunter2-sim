# AgentVLN × HUNTER 2.0 复现要求与进度汇总

本记录按顺序整理最初的复现要求、后来的 VLM 增量要求与两项卡点，以及截至 **2026-11-09** 有运行证据的结果。

## 一、最初的论文复现要求

在已有 HUNTER 2.0 实验室仿真上，用一句包含**地标、经过顺序和停靠关系**的指令，让虚拟车根据第一视角选路。目标进入视野后，用深度把画面里的目标换算成可停靠位姿，由现有 Nav2 执行运动。例如「经过红牌，在两个蓝箱中较远的那个前方停下」。

首轮范围是在已知实验室地图上验证论文机制。用固定地图生成可达路点，用 HUNTER 能驶达的观察位姿处理遮挡。原定范围把 Habitat R2R-CE / RxR-CE 榜单、全量指令微调和 Go2 / Jetson 部署留作独立任务。 [最初的桌面 Prompt](C:/Users/ASUS/Desktop/AgentVLN_HUNTER仿真复现指导Prompt.md) · [论文 §3–4](https://arxiv.org/html/2603.17670v1#S3)

| 步骤 | 当时要求 |
|---|---|
| **1．固定导航基线与接通相机** | 复用实验室地图、AMCL 和冻结的 `nav2_params_fix.yaml`，从运行中的 Nav2 读回参数。复测已知坐标到点、取消、停稳。在场景与桥接的副本中接入 RGB、深度和 CameraInfo，校验同步、光学 TF、内参、深度单位、投影、测距和反投影。静止与行驶中都要取到新帧。 |
| **2．图像选路与到点技能** | 在直道和可通过的弯道设置地标。根据自由空间、车体轮廓、转弯半径和试规划筛选路点，按图像时刻的 TF 投影到 RGB 并编号，剔除视野外与遮挡的候选。Agent 根据指令、图像、候选与历史结果选择技能，执行器校验帧和位姿，再让 Nav2 逐段到点。先用规则或回放调通接口，再接真实 VLM。 |
| **3．局部深度定位与纠偏** | 目标未见时逐段行驶，遇遮挡时在预算内换到可达位姿再观察。目标可见后查询两个区域的同帧深度，记录查询前后选择，以相机内参和 TF 反投影，由几何模块生成满足车体净空的停靠位姿。用独立停车区验收，超时按仿真时间和墙钟管理，取消须取得动作终态并确认停稳。 |
| **4．验收与交付** | 至少 6 个任务，每任务每模式至少重复 3 次，覆盖地标、转弯顺序、目标歧义或遮挡。同批比较已知坐标基线与视觉闭环，分别开关画面编号、主动深度查询、纠偏。以经过指定区域的顺序、停车区和停稳为原定验收项，分别记录任务结果与动作状态，并保存配置、日志、图像、轨迹、耗时、失败样例和复现入口。 |

### 执行边界

- 平台为 Windows 台式机、WSL2 Ubuntu 22.04、ROS 2 Humble 和 Gazebo Fortress。虚拟运动前核对 ROS 域 `73`、`ROS_LOCALHOST_ONLY=1`、CycloneDDS、独立 Gazebo 分区和速度桥方向。所有实验限定在仿真，实车域 `88` 排除在范围外。
- 地图、冻结 Nav2 参数和原世界文件作为复用基线，实验改动写入独立副本。模型通过结构化接口调用感知和到点技能，速度控制交给 Nav2。
- 地图与场景版本、初始位姿、指令、模型版本、预算、种子和逐轮证据一并归档。Gazebo 真值与标注停车点用于独立评分及已知坐标对照。接触测不到时标 `not_measured`，SPL 需要相同运动约束下独立计算的最短参考路径。
- 实验结束按登记表清理本次仿真进程。如需用户协助，一次给一条命令或一个操作，等待回传。

## 二、后来的增量要求

### 2.1 把规则选箱替换为真实 VLM 决策

前四步先搭好相机、候选、深度反投影和运动执行，再把决策交给真正接收图像与指令的模型。继续使用同一套地图、相机几何、AMCL 和 Nav2。 [增量方案原文](D:/rob-memory/sim/experiments/agentvln_hunter/PLAN_vlm_step.md)

1. **先做单帧验收。** 输入 RGB、中文指令、编号及像素区域。输出结构化动作 `query_depth(candidate_id)`、`select_target(candidate_id)`、`request_reobserve` 或 `finish`，保留每步 trace、工具回执、模型版本和耗时。后端未就绪时，先验收 JSON 回放接口，真实推理单独标待测。
2. **构造远箱反而更大的布局。** 同一帧分别问「停在较远的蓝箱前」和「停在较近的蓝箱前」。交换场景中的远近或大小关系，检查选择是否随画面变化。以面积规则作对照，在同一批任务配对比较画面有无编号、是否开放主动深度查询。关闭查询时保留最终几何反投影能力。
3. **接回在线行驶。** 先测包含红牌、蓝牌通道和远箱停靠的顺序任务，用真值轨迹核对经过顺序。再测起点只看见部分目标时，模型能否主动请求换位并用新画面继续。耗时区分模型请求、工具调用和 Nav2 执行。增量先做小批量配对，沿用此前 36 轮基线。
4. **分层交付。** 将规则基线、VLM 离线验收、VLM 在线闭环分别记录，保存图像、指令、每步决策、轨迹和验收结果。
