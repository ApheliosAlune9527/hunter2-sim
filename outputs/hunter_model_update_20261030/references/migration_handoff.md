# 给台式机 Agent 的交接说明

请先阅读 00_先读我.md、本文件与 02_文件清单.json。用户希望在已有的 2026-10-21 迁移基础上同步这几天的成果，并继续规划 Hunter 车辆仿真、强化学习、Agent 和世界模型研究。

## 使用与同步原则

- 本包是增量，不是完整的 ROS 环境或完整项目；先确认台式机上先前迁移包和目标项目目录的实际位置。
- 项目增量按旧笔记本 F:/rob-memory 的相对路径保存。对照文件清单的旧 SHA256 和当前 SHA256；台式机上已有不同内容时保留冲突副本，先比较再合并。
- 用户已明确说不需要重传 Ubuntu 仿真环境；沿用台式机原有版本。笔记本 VHDX 在基线后变化，内容尚未比较，不能声称两机系统完全一致。
- 桌面 PPT 和项目输出 PPT 的内容不同，分别保留；不要仅凭文件名或时间覆盖。
- 不覆盖、替换或重建台式机现有 Codex 数据库。聊天原始 JSONL 和可阅读摘录可作为参考资料使用，不保证在应用聊天列表自动出现。
- 如果需要真实小车最新文件，以后与用户确认后再只读核对；本包并未直接连接或复制车端工作区。

## 已确认的项目背景

- 车辆铭牌为松灵 HUNTER 2.0 阿克曼底盘。官网参数：轴距 0.650 m、轮距 0.605 m、最高速度 1.5 m/s；2023 年官方手册给底盘尺寸 980×745×370 mm，最小转弯半径 1.6 m。官网与手册最小离地间隙分别为 100 mm 和 105 mm，待实机或厂家核实。产品页：https://www.agilex.ai/products/hunter
- 当前 RViz 使用 /hz_nav/robot_description，由 robot_state_publisher 发布。引用 hunter_description 的车体与传感器网格以及 realsense2_description 的相机网格。此前检查运行中的 URDF、车端保存的 URDF 和本机展开版本的规范化 SHA256 一致：9e1112e0bbc029ff5d4de3966410e37531bf464c7ffb0aa59026450e1b86675b。
- 用户希望仿真尽量复用现有车辆外观和已验证资产，同时需要可运动、可感知的仿真；RViz 中能显示外观并不代表完整物理仿真已经完成。
- 原 Nav2 学习任务优先复用师兄的配置和已验证资产，不把静态规划、隔离速度链路验证或 RViz 显示称为实车自主导航已完成。
- 根据本机项目记录，截至对应文件的快照：地图、激光、里程计与定位接口已接入；一次静态短路径规划成功；隔离输出的速度链路、局部代价地图的基础查看已有证据。真实导航、行驶与停止的完整验证以随后实际证据为准。
- 主聊天仍在进行，状态会继续变化；请读取本包 项目增量/task_plan.md、progress.md、findings.md 及聊天末尾，注意时间和证据来源，勿据旧记录假定实车状态。
- 用户在侧聊提出长期方向：先在个人电脑构建仿真并验证，再向实车迁移；后续加入强化学习、Agent、世界模型。框架尚在规划阶段，不要把这些设想描述为已经实现。
- 当前这台打包电脑是 Windows 11、16 GB 内存、RTX 3050 Laptop 4 GB；用户明确说将来的台式机是另一台，其硬件与系统以台式机实查为准。
