# 个人 HUNTER 2.0 简化仿真模型

此包提供独立的简化物理骨架：一个箱体、四个圆柱车轮、两个前轮转向节，共7个连杆、6个运动关节。每个连杆都有正质量和按箱体/圆柱公式计算的惯性。包内模型本身没有控制插件、ROS节点、硬件驱动或启动文件；控制器与运行入口位于独立场景和工具目录。

基础仿真按运动结构、控制与观测、真实外观和传感器对齐逐步推进。独立场景已有低速直行验证记录；用户GUI完整直行、转弯、里程计与传感器集成的状态，以outputs/hunter_sim_execution_20261012/task_plan.md为准，不能据此声称实际车辆动力学已标定。

2026-10-30已根据新增铭牌照片确认实车为HUNTER 2.0，并确认本机原展开URDF的规范化哈希与迁移记录一致。完整来源与参数对照见[模型资料核对](F:/rob-memory/outputs/hunter_model_update_20261030/README.md)。本次只更新来源文档，没有修改Xacro、场景、控制参数或执行运动。

## 坐标与后续接口

骨架的base_link定义在后轴轮心连线中点，X向前、Y向左、Z向上；轮心位于base_link的Z=0，放到地面上时该坐标原点约为轮半径高度。箱体中心在X=轴距/2、Z=0.12 m。车轮转轴为Y，前轮转向轴为Z；正车轮角速度对应向前滚动，正转向对应向左。

这是个人骨架的明确定义，尚未核实是否与实车模型base_link原点重合。导出的固定模型作为独立外形和坐标参考保留，不能不经对齐就把其中的传感器安装坐标直接套到此骨架。当前也不直接复用旧Nav2的footprint。

后续仿真控制与ROS桥接应使用/hz_sim下的独立控制话题，并在个人域73及本机通信限制经运行核对后启用。控制插件方案参考[Fortress AckermannSteering文档](https://gazebosim.org/api/gazebo/6/classignition_1_1gazebo_1_1systems_1_1AckermannSteering.html)，当前骨架文件尚不包含该插件。

离线XML/SDF检查只确认格式及结构；独立场景的运行证据另行记录，不能将其扩大为整车动力学、实车外参或完整导航验收。真实外观参考URDF的9个关节全部固定，尚需与本包的运动结构和坐标原点对齐。
