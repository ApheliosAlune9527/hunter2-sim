# Hunter 项目增量迁移：先读我

这是在 2026-10-21 原完整迁移包基础上制作的更新包，供你传到台式机后交给那边的 Agent 阅读、核对和同步。

## 你需要做什么

1. 把本 ZIP 传到台式机，解压到一个新的空文件夹。
2. 将解压后的 01_给台式机Agent的交接说明.md 发给台式机上的 Agent，或者让它直接打开该文件。
3. 让 Agent 先检查台式机原有项目和旧迁移结果，再按文件清单比较、合并；存在同名差异时保留已有内容和增量副本，避免直接覆盖。
4. 在台式机核验完成之前，保留这台电脑上的原件及旧迁移包。

## 本包包含

- 项目增量：按 F:/rob-memory 的相对路径保存，上次迁移之后新建或改变的项目文件。
- 桌面单独成果：笔记本桌面上的汇报 PPT，与项目交付目录中的同名 PPT 内容不同，两版都予保留，不假定哪一版是台式机需要的。
- 聊天记录/原始会话文件：和 Hunter 导航、此前迁移相关的原始 JSONL 文件，按原样截取到完整行。部分文件也包含基线之前的内容。
- 聊天记录/可阅读版本：从上述原始文件摘取的基线后用户和助手消息；嵌入截图另存为图片。工具轨迹请查原始会话文件。
- 聊天记录/粘贴文本附件 和 侧聊截图：本机仍可读到的相关附件。
- 文件清单 JSON 和 SHA256 校验表，可用于比较来源和检查传输。

## 范围及注意

- 按用户要求，不重新打包 Ubuntu 的 WSL 虚拟磁盘（ext4.vhdx）。该文件在旧快照后有修改时间及大小变化，本次没有比较其内部变化；台式机继续使用之前迁移的环境。
- 当前侧边对话为临时会话，应用接口不支持直接导出其原始对话；其关键内容写入交接说明，截图尽可能保留。不要将摘要称为逐字记录。
- 车载 Linux 的最新目录未直接连接或复制。截图、聊天和本机项目文件能作为证据，但不能当作车端实时状态或最新文件的完整备份。
- 本包可供 Agent 读取聊天，不代表自动导入到 Codex 历史界面。不要用这些文件覆盖台式机现有的 Codex 数据库。
- 主导航会话仍可能继续，所有进度只代表各源文件的打包时刻。
