# 下一轮补扫流程

目标：保留本轮作为基准，改善桌椅背面及中部遮挡区的覆盖，记录可比的起终位置与朝向。沿用现有算法参数、每批写盘设置和内存检查，先改善采集条件。

## 先做静止核对

- 查看本目录 `lab_top_view.png`。左右两侧设备和中部桌椅存在未观察到的区域；白色区域也可能是高度切片没有保留地面，应结合现场判断。
- 确认外围点群是否对应窗外或邻室。没有实物对应信息前，保留这些成片点群。
- 选已有地砖缝或地面标记作为起点，记录小车相对它的位置与朝向。有卷尺时，再记录一段已知距离供后续比较。

## 手持遥控补扫

**这一部分会实际移动小车。开始前必须拔掉充电线，确认现场空闲并有人控制原有手持遥控器。监看程序只停止计算程序，不会替你刹车。**

1. 在记录的起点静止约 20～30 秒，等待初始化。
2. 用较慢且平稳的速度沿实验室通道绕行，转弯时减速；避免急加速和急转弯。
3. 在安全通道内从另一个方向观察桌椅和设备背面。若有条件，补一段中部通道；不要为补盲区驶入狭窄空间。
4. 回到地面标记处，尽量保持相同位置、相同朝向，静止约 20 秒。记录实际偏移，后续才能区分停车差异与估计误差。
5. 总采集先控制在约 3～5 分钟。监看程序提示内存或磁盘不足时，先用遥控器让小车停稳。

本轮原始记录显示主要绕行约 84 秒，其余大量时间停在起点附近。下一轮把时间更多用于不同方向的观察，避免在一个位置积累大量重复点。

## 停止并下载

先用遥控器停稳。按 Ctrl+C 退出监看，随后依次执行：

```bash
python3 -B /home/car/hz_ws/scripts/hz_mapping_session.py stop
python3 -B /home/car/hz_ws/scripts/hz_mapping_session.py check
python3 -B /home/car/hz_ws/scripts/hz_mapping_session.py pack
```

确认每条命令成功后，Windows PowerShell 中执行：

```powershell
$hzRobotIp = Read-Host '输入小车当前 IP'
powershell -NoProfile -ExecutionPolicy Bypass -File 'F:\rob-memory\hz_mapping_tools_20261011\download_map.ps1' -RobotIp $hzRobotIp
```

新一轮下载到独立运行目录，不覆盖本轮。然后用与本轮相同的几何检查比较覆盖范围、平整墙面分布及实际返回位置。

## 后续标定检查

若补扫后仍有明显重复轮廓或颜色错位，再用短时原始传感器录包检查相机/雷达外参与时间偏移；当前只有彩色点云和日志，无法独立重算。需要录包时先检查可用磁盘和输入 QoS，再给出对应命令。
