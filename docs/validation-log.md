## 约定

1. 上车前：先 `git commit`，再 `git push`，确认笔记本拉到的是同一个 commit。
2. 验证通过：`git tag -a v0.1-robot-ok -m "实验室直线+避障，雷达正常"`，然后 `git push --tags`。
3. 验证失败：同样记一行，写清现象（打滑、定位漂移、话题丢帧…），方便回滚对照。
4. 参数改动必须落在 `config/` 下的配置文件里，日志里只写"改了哪个文件/哪几个值"。
